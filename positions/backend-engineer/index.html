백엔드 엔지니어 (Core HR)

개발5년 이상정규직Core HR

이 포지션이 풀 문제

인사 데이터는 "지금 상태"만으로 답할 수 없는 도메인입니다. 3년 전 발령 시점의 소속으로 소급 계산해야 하는 정산, 겸직·파견처럼 한 사람이 두 조직에 동시에 속하는 구조, 법인이 다른 해외 지사의 인사 규정. 이 포지션은 시간과 조직 구조가 얽힌 데이터 모델을 설계하고, 1,400개 고객사의 서로 다른 인사 규정을 하나의 스키마 위에서 돌아가게 만듭니다.

주요 업무

  • Core HR 도메인의 데이터 모델 및 API 설계·개발
  • 발령 이력, 겸직, 소급 처리 등 시계열 인사 데이터 구조 고도화
  • 멀티테넌시 환경에서의 데이터 격리 및 성능 보장
  • 타 모듈(Performance, Insight, Flow)에 제공하는 내부 API 정의

자격 요건

  • 백엔드 개발 경력 5년 이상
  • JVM 기반 언어(Kotlin/Java)로 실서비스를 설계·운영한 경험
  • 복잡한 도메인을 데이터 모델로 옮겨본 경험과 그 판단 근거를 설명할 수 있는 능력
  • RDBMS 쿼리 성능 분석 및 인덱스 설계 경험

우대 사항

  • 인사·급여·회계 등 규정이 복잡한 도메인 경험
  • 이벤트 소싱, 감사 로그(audit trail) 설계 경험
  • 멀티 리전 또는 다국가 서비스 운영 경험

함께 일할 팀

Core HR 스쿼드는 백엔드 4명, 프론트엔드 2명, PM 1명, 디자이너 1명으로 구성된 크로스펑셔널 조직입니다. 스펙은 PM이 혼자 쓰지 않고, 도메인 모델링 단계부터 엔지니어가 함께 참여합니다.
