프론트엔드 엔지니어

개발3–7년정규직Web Platform

이 포지션이 풀 문제

스펙트라의 화면에는 38만 명의 인사 데이터가 올라옵니다. 조직도 하나를 그리려 해도 노드가 수천 개고, 평가 시즌에는 한 화면에서 수백 명의 상태가 동시에 바뀝니다. "데이터가 많으면 화면이 느려진다"를 당연하게 받아들이지 않는 사람이 필요합니다. 이 포지션은 대용량 데이터를 다루는 B2B 화면에서 정확성과 반응 속도를 동시에 지키는 방법을 설계합니다.

주요 업무

  • Core HR·Performance·Insight 모듈의 웹 프론트엔드 개발
  • 수천 개 노드 규모의 조직도, 대시보드 등 대용량 렌더링 최적화
  • 4개 모듈이 공유하는 디자인 시스템 컴포넌트 설계 및 유지보수
  • 프로덕트 디자이너와 함께 인터랙션 명세를 정의하고 구현 가능성을 조율

자격 요건

  • 프론트엔드 개발 경력 3년 이상
  • React와 TypeScript로 실서비스를 운영해본 경험
  • 렌더링 성능 병목을 측정하고 개선해본 경험 (가상 스크롤, 메모이제이션 등)
  • 디자인 시스템 또는 공용 컴포넌트를 만들어 다른 팀이 쓰게 해본 경험

우대 사항

  • B2B SaaS, 특히 데이터 밀도가 높은 어드민 제품 경험
  • 웹 접근성(WCAG) 기준을 실제 제품에 적용해본 경험
  • 데이터 시각화 라이브러리를 커스터마이징해본 경험

함께 일할 팀

Web Platform 팀은 프론트엔드 엔지니어 6명, 프로덕트 디자이너 2명으로 구성되어 있습니다. 모듈별 스쿼드에 파견되어 일하되, 격주 목요일 플랫폼 싱크에서 공용 컴포넌트에 대한 결정을 함께 내립니다.
